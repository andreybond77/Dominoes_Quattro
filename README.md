# 🁫 Dominoes-Quattro

Браузерная логическая игра в домино (4×4) против ИИ. Выкладывайте костяшки, совпадайте цифрами и набирайте очки.

**[🎮 Играть в демо](https://andreybond77.github.io/Dominoes_Quattro /)** · **[📂 Исходный код](https://github.com/andreybond77/dominoes-quattro)**

---

## ✨ Возможности

- **Три уровня сложности ИИ:**
  - 🟢 Лёгкая — случайный выбор хода.
  - 🟡 Средняя — ИИ ставит костяшку с максимальным числом совпадений.
  - 🔴 Сложная — ИИ **просчитывает ваш лучший ответный ход** и выбирает ход, который минимизирует ваш выигрыш (`bestPlayerResponseScore`).
- **Механика «жёлтых клеток»** — после второго хода на поле появляются запрещённые зоны, блокирующие размещение.
- **Карусель костяшек** — 7 слотов с бесконечной прокруткой, активная костяшка в центре.
- **Drag-and-drop** — панорамирование игрового поля мышью и пальцем.
- **Предпросмотр хода** — при наведении показывается зелёный (валидный) или красный (невалидный) контур.
- **Сохранение статистики** в `localStorage` (победы, поражения, ничьи, очки, ходы).
- **Web Audio API** — синтез звуков без внешних файлов.
- **Адаптивность** — от 320px до 900px.

## 🛠 Технологии

| Слой | Что использовано |
|------|------------------|
| Логика | Чистый JavaScript (ES6+) |
| Рендеринг | DOM (CSS Grid), без Canvas |
| ИИ | Эвристический поиск + просчёт ответа игрока |
| Звук | Web Audio API |
| Хранение | localStorage |
| Стили | CSS3 (Grid, Flexbox, media queries) |

**Без зависимостей.** Никаких фреймворков и сборщиков.
